Game Verse

Platform game dengan AI adaptif yang membuat pengalaman bermain lebih hidup

Tentang Game

Game Verse adalah platform game futuristik dengan sistem AI adaptif yang menganalisis gaya bermain pemain dan menyesuaikan tingkat kesulitan, musuh, dan alur cerita secara real-time untuk menciptakan pengalaman bermain yang imersif dan tidak monoton.

Keunggulan

  • Sistem AI adaptif yang belajar dari gaya bermain pemain.
  • Level dinamis dan environment yang berubah secara real-time.
  • Pengalaman bermain personal berdasarkan performa pemain.

Flowchart & ERD

Teknologi yang Digunakan

  • Unity Engine + C#
  • Machine Learning API
  • Photon Engine (Multiplayer)
  • PostgreSQL
